  2. Enter your WebSocket URL (e.g., wss://your-api-id.execute-api.region.amazonaws.com/prod)
  3. Click "Connect" to establish WebSocket connection
  4. Use "Get All Latest" to fetch initial data
  5. Select sensors and subscribe to real-time updates
